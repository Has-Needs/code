# Need Configurator — planned prototype

**Status:** Design fixture only; **no executable prototype or experimental results yet**.

**Question:** Can someone express a desired outcome intuitively while their Persona Manager encodes it as a self-contained `NEED` holding conditions, permissions, and optional logic?

The Need is the smart contract, not a separate agreement object or execution room. The prototype should support human-readable conditions, relevant contextual scope, and selected disclosure through a user-created persona. Later accepted exchanges proceed through `WORKING` and the independently reviewed ready-to-commit flow.
